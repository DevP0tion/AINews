## AI/IT 뉴스
### "문제는 AI가 쓴 코드가 아니라, 아무도 시스템을 모른다는 것"
AI 코딩 도구의 결과물 자체보다 조직의 지식 소실이 진짜 문제라는 주장이다. 저자는 코드 생성이 쉬워질수록 아키텍처와 설계 의도를 이해하는 사람이 줄어 유지보수가 어려워지고, 특히 신규 인력이 기본기를 익힐 기회를 잃는다고 지적한다. AI는 스스로 방향을 정할 수 없으므로 의도·취향·아키텍처 판단은 사람이 제공해야 하며, 주니어 채용과 멘토링을 포기한 것이 스스로 만든 문제라고 본다.
[원문](https://www.ssp.sh/brain/the-problem-is-not-the-ai-code-but-nobody-knows-anything-anymore/)

### 프롬프트에 "추측하지 마라" 한 줄 추가로 웹 추출 환각이 70.7% → 20.2%
웹 페이지에서 구조화 데이터를 뽑는 과제에서 "페이지에 없는 값은 null로 두고 추측하지 말라"는 지시 한 줄의 효과를 측정한 벤치마크다. 지시가 없을 때는 누락 필드 573개 중 405개(70.7%)가 지어낸 값이었고, 지시를 넣으면 574개 중 116개(20.2%)로 줄었다. 모델 16종과 유료 API 3종을 비교해 Gemini 3.8 Flash가 36개 중 1개로 가장 좋았고 Firecrawl이 24개로 가장 나빴다. 단 컨테스트당 1회 실행, 합성 테스트 페이지, 유료 API는 무료 티어만 사용한 조건이라는 한계를 저자가 밝히고 있다.
[원문](https://earnanhonestdollar.com/bench)

### Cloudflare, 에이전트를 겨냥한 통합 CLI `cf` 오픈 베타 공개
Cloudflare가 자사 API 전체(3,000개 이상 오퍼레이션)를 하나의 CLI로 다루는 `cf`를 오픈 베타로 내놨다. 기본 출력이 JSON이고 자연어 명령 검색(`cf cli search`)을 제공하는 등 사람보다 AI 에이전트의 사용을 전제로 설계했으며, 발표 시점 Wrangler 사용의 48%가 에이전트였다고 밝혔다. 약 280개 명령의 Wrangler를 대체하며, 오픈 베타 종료 시 Wrangler의 마지막 메이저 버전을 내고 이후 18개월간 유지보수한다. OpenAPI 스키마에서 CLI 명령을 생성하는 내부 SDK 제너레이터 `Forge`도 오픈소스로 공개했다.
[원문](https://blog.cloudflare.com/cloudflare-cf-cli-launch/)


## Claude/Anthropic 업데이트
### 모델/API
- **Claude Sonnet 5.5 출시 (Claude API·Bedrock·AWS·Google Cloud·Microsoft Foundry)** ⚠️
  Claude Sonnet 5.5(`claude-sonnet-5-5`)가 Claude API와 Amazon Bedrock, Claude Platform on AWS, Google Cloud, Microsoft Foundry에서 출시됐다.
  [출처](https://platform.claude.com/docs/en/models/sonnet-5-5/overview)
- **Sonnet 5 → Sonnet 5.5 마이그레이션 시 깨질 수 있는 5가지 변경** ⚠️
  Sonnet 5용 코드가 Sonnet 5.5에서 깨질 수 있는 지점으로 up-front thinking 해제 시 `thinking: {"type": "between_tools"}` 사용(high 이하 effort), 강제 tool use(`tool_choice`의 `any`·`tool`) 400 오류, thinking 블록의 모델·대화 종속, Claude API와 Google Cloud에서 구버전 `computer_20251124` computer use 툴 미지원, advisor 툴이 Claude Opus 4.8·4.7·Sonnet 5을 advisor로 거부하는 점이 안내됐다.
  [출처](https://platform.claude.com/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5)
- **Sonnet 5.5의 thinking 블록은 생성한 계정(및 연결 계정)에서만 유효**
  Claude Sonnet 5.5가 만든 thinking 블록은 이를 생성한 계정이나 연결된 계정에서만 동작하며, 다른 계정이 보내면 API가 해당 블록을 모델에 전달하기 전에 제거하고 요청은 정상 처리된다(이전 모델의 블록은 영향 없음).
  [출처](https://platform.claude.com/docs/en/build-with-claude/preserved-thinking)
