## AI/IT 뉴스
### 확산 언어 모델(Diffusion Language Model) 구축 방법
확산 언어 모델은 좌우 순차 생성 대신 마스킹된 토큰을 반복적으로 채워 넣는 방식으로 텍스트를 생성하는 아키텍처로, 전방 과정에서 토큰을 점진적으로 마스킹하고 역과정에서 트랜스포머가 원래 토큰을 예측하도록 학습시킨다. 병렬 토큰 생성과 반복적 오류 수정이 가능해 기존 자기회귀 모델 대비 최대 5~10배 빠른 추론이 가능하며, Mercury 2 같은 상용 모델은 초당 1,000토큰 처리 속도를 달성했다.
[원문](https://kuleshov-group.github.io/blog/blog/2026/how-to-build-a-diffusion-language-model/)

### 보안 연구자, Claude Code Opus 5 Auto Mode에서 원격 코드 실행 체인 시연
한 보안 연구자가 HTTP 415 오류 유도, 악성 ZIP 아카이브 전달, 표준 라이브러리 모듈(struct.py) 섀도잉 등을 결합한 다단계 공격 체인으로 Claude Code Auto Mode에서 60~80% 확률의 원격 코드 실행에 성공했다고 밝혔다. Anthropic이 72개 고정 시나리오 테스트에서 공격 성공률 0%라 밝혔지만 해당 공격 체인은 이 테스트셋에 없던 새로운 경로였으며, 연구자는 안전 분류기만으로는 부족하고 샌드박싱이 필수적이라고 지적했다.
[원문](https://embracethered.com/blog/posts/2026/breaking-claude-code-opus-5-and-automode/)

### Simon Willison, OpenAI 유료 기능 'ChatGPT Work' 실체 분석
월 20달러 이상의 유료 기능인 ChatGPT Work는 무제한 인터넷 접속 코드 실행, 헤드리스 브라우저, 세션 간 유지되는 공유 파일시스템, Cloudflare Workers 기반 사이트 배포, 서브에이전트 병렬 실행 등을 지원하는 클라우드 에이전트 환경이다. Willison은 OpenAI가 실제 시스템 프롬프트와 툴 정의를 공개하지 않아 역공학이 필요했다고 지적하며, 민감 데이터와 미검증 콘텐츠가 결합되는 보안 위험(lethal trifecta)을 제기했다.
