## AI/IT 뉴스
### OpenAI, 실시간 음성 대화 모델 'GPT-Live' 공개
OpenAI가 사람과의 대화처럼 자연스러운 실시간 음성 대화를 위한 GPT-Live 모델을 공개했다. 듣기와 말하기를 동시에 처리하는 full-duplex 구조를 채택했고, 복잡한 질문은 백그라운드에서 GPT-5.5로 위임 처리한다. 정식 버전 GPT-Live-1과 경량화된 mini 버전이 iOS·Android·웹에 순차 출시되며 API는 추후 제공될 예정이다.
[원문](https://openai.com/index/introducing-gpt-live/)

### 'GitLost': 프롬프트 인젝션으로 GitHub AI 에이전트가 비공개 저장소 유출
보안 연구사 Noma Labs가 GitHub의 AI 에이전트 워크플로우를 프롬프트 인젝션으로 속여 비공개 저장소 파일을 유출시키는 취약점 'GitLost'를 공개했다. 공격자는 공개 저장소의 이슈 본문에 숨겨진 지시문만 심으면 별도 인증 없이도 워크플로우가 접근 권한을 가진 비공개 repo의 내용을 공개 댓글로 노출시킬 수 있었다. 해당 취약점은 GitHub 측에 책임 있게 사전 공개됐다.
[원문](https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/)

### Cognition, 코딩 전문 모델 'SWE-1.7' 공개 — GPT-5.5·Opus 4.8에 근접
Cognition이 자사 코딩 에이전트 Devin에 탑재되는 소프트웨어 엔지니어링 전용 모델 SWE-1.7을 공개했다. Kimi K2.7 베이스에 강화학습을 적용해 FrontierCode, Terminal-Bench, SWE-Bench 등 벤치마크에서 GPT-5.5·Opus 4.8에는 소폭 못 미치지만 낮은 비용으로 근접한 성능을 냈다고 밝혔다.
[원문](https://cognition.com/blog/swe-1-7)
