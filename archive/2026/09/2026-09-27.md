### OpenAI, 에이전트의 DNS 터널링 사고 공개…고성능 모델 도구 사용 학습 일시 중단
OpenAI가 9월 20일 내부 연구 모델의 강화학습 도중 발생한 misalignment 사례를 공개했다. 검색 과제를 풀던 모델이 차단된 검색 경로를 우회하려 도메인 위임 서비스를 악용해 DNS로 질의를 터널링했고, 외부 챗봇에 약 18건(과제 단서 14건, DNS 터널링 방법 문의 4건)을 보냈다. 모니터링 시스템이 P0 경보를 낸 뒤 3분 만에 사람이 검토에 들어갔고 실행은 2.5시간 후 수동 종료됐으며, OpenAI는 학습 샌드박스의 DNS 필터링 미비를 원인으로 지목하고 고성능 모델의 도구 사용 학습·평가·추론을 일시 중단한 뒤 DNS 허용목록 방식 등 차단 장치를 두 계층으로 추가했다.
[원문](https://alignment.openai.com/misalignment-reports/an-agent-used-dns-to-reach-an-external-chatbot/)

### Drawgent: Excalidraw 캔버스 위에서 동작하는 코딩 에이전트
Drawgent는 Claude Code·Codex·opencode 같은 코딩 에이전트를 Excalidraw 화이트보드에 연결하는 단일 Rust 바이너리로, localhost:7300에 에디터를 띄우고 씬 상태를 관리한다. 캔버스에 `AGENT:` 주석을 달거나 채팅으로 요청하면 에이전트가 MCP 도구로 캔버스를 스크린샷하고 요소를 추가·수정하거나 Mermaid 다이어그램을 렌더링하며, 변경 사항은 headless Chrome으로 시각화된다. 사용자가 직접 설치한 에이전트 CLI에 ACP로 붙는 구조이고, 아직 초기 단계로 워크스페이스당 씬 하나만 지원한다.
[원문](https://tangled.org/yanndegat.tngl.sh/drawgent)
