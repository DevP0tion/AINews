## AI/IT 뉴스
### MCP is dead?
Quandri 엔지니어링팀이 Model Context Protocol(MCP)의 실용성에 의문을 제기했다. MCP 서버 4개 스택이 컨텍스트 윈도우의 10.5%를 소비하고 세션 중 충돌·성능 저하가 빈번하며 기존 CLI·API 도구와 기능이 중복된다는 게 주요 논거다. 대안으로 CLI 우선 전략과 필요 시에만 도구 정의를 로드하는 Skills 패턴을 권장했다.
[원문](https://www.quandri.io/engineering-blog/mcp-is-dead)
