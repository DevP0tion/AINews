## AI/IT 뉴스
### Microsoft starts canceling Claude Code licenses
Microsoft가 임직원에게 제공하던 Claude Code 라이선스를 종료하고 자사 Copilot으로의 전환을 강제하기 시작했다. 개발자 다수가 두 도구를 모두 사용할 수 있었을 때 Claude Code를 선호했으나, Microsoft는 Copilot CLI 사용량이 자연 증가했다는 내부 데이터를 근거로 이번 결정을 발표했다. 직원들은 여전히 다른 경로를 통해 Anthropic 모델에 접근할 수 있으며, Opus 4.6은 계속 사용 중이다.
[원문](https://www.theverge.com/tech/930447/microsoft-claude-code-discontinued-notepad)
