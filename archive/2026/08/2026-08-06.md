### Stateless MCP has recaptured my interest
Simon Willison이 MCP(Model Context Protocol)의 새로운 'Stateless' 버전에 다시 주목한 이유를 설명합니다. 기존에는 세션 초기화 후 도구를 호출해야 했지만, Stateless MCP는 단일 HTTP 요청만으로 동작해 구현이 단순해지고 서버 측 상태 관리가 필요 없어 웹 확장성도 좋아졌으며, 임의 셸 명령 실행보다 에이전트 동작을 명확히 통제할 수 있어 보안성도 높다고 평가했습니다.
[원문](https://simonwillison.net/2026/Jul/31/stateless-mcp/)
