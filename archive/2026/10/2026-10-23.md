## AI/IT 뉴스
### NVIDIA, 자율 AI 에이전트용 샌드박스 런타임 'OpenShell' 오픈소스 공개
NVIDIA가 자율 AI 에이전트를 안전하게 실행하기 위한 오픈소스 런타임 OpenShell을 공개했다. 에이전트가 접근할 수 있는 파일·시스템 콜·네트워크·자격증명을 정책(policy)으로 선언하면 커널 수준 제어로 이를 강제하고, 자격증명은 에이전트에 노출하지 않고 승인된 엔드포인트로 가는 요청에만 주입한다. 정책 변경 시 formal verification으로 위험한 신규 접근 권한을 걸러 사람 검토로 넘기며, Python·TypeScript·Go·Rust SDK와 Helm 기반 Kubernetes 배포를 지원한다(Apache-2.0, 0.1.x 릴리즈 라인).
[원문](https://github.com/NVIDIA/OpenShell)

### "LLM에 신뢰도 점수를 물어보는 것은 좋은 방법이 아니다"
LLM이 출력하는 confidence score는 다른 텍스트와 같은 방식으로 생성된 토큰일 뿐이고, 실제 정답률에 맞춰 캘리브레이션되도록 학습된 값이 아니라는 주장이다. 같은 질문을 다시 물으면 점수가 0.85에서 0.7로 바뀌거나, 표현을 바꾸거나 "확실한가?"라고 되묻는 것만으로 점수가 흔들리고, 앞선 문맥이 점수를 끌어올리는 현상을 근거로 든다. 저자는 LLM 외부에서 로그 기반 규칙으로 신뢰도를 계산할 것을 권한다 — 과거 정답률을 기저율로 삼고, 출력·점수·정답 여부를 기록해 비슷한 조건의 그룹별 실측 정확도를 점수로 쓰고 주기적으로 캘리브레이션을 점검하는 방식이다(통제된 실험 데이터는 제시되지 않았다).
[원문](https://rumple.github.io/blog/2026/10/20/asking-llm-for-confidence.html)

### OpenAI, REST API용 공식 커맨드라인 도구 'openai CLI' 공개
OpenAI가 REST API를 터미널·셸 스크립트에서 직접 호출할 수 있는 공식 CLI를 공개했다. Go로 작성됐고 Apache-2.0 라이선스이며, `openai images generate`·`openai files upload`·`openai batches create`처럼 API 리소스 단위로 명령이 구성된다. JSONL 배치 제출·결과 다운로드, `OPENAI_ADMIN_KEY`를 쓰는 어드민 엔드포인트, `--format json/jsonl`과 GJSON 문법의 `--transform` 같은 스크립팅 지향 옵션을 제공한다. 코드를 읽고 수정하는 코딩 에이전트인 Codex CLI와 달리 API 호출·스크립팅 용도로 역할이 구분된다.
[원문](https://github.com/openai/openai-cli)
