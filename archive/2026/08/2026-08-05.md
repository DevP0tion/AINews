## AI/IT 뉴스
### AURORA-LM: 연속 잠재 공간 기반 Diffusion 언어 모델링
이미지·오디오와 달리 텍스트 생성은 여전히 이산 토큰에 의존해온 한계를 극복하기 위해, 디코딩 가능한 텍스트 표현 구축과 분포 모델링을 분리하는 continuous-latent diffusion 모델 AURORA-LM이 제안되었다. Query 기반 인코더-디코더로 고용량 텍스트 표현을 만들고, flow matching을 사용하는 Block-causal Diffusion Transformer로 분포를 학습해 텍스트 생성·요약 벤치마크에서 디코더 성능 저하 없이 우수한 결과를 보였다.
[원문](https://arxiv.org/abs/2608.02602v1)

### AI 벤치마크 포화 현상에 대한 체계적 연구
연구진이 60개 언어모델 벤치마크를 14가지 포화 관련 지표로 분석한 결과, 절반 가까운 벤치마크가 포화 상태이며 오래된 벤치마크일수록 포화율이 높아지는 것으로 나타났다. 테스트 데이터의 공개 여부보다 전문가 큐레이션 여부가 벤치마크의 유효 수명을 좌우하는 핵심 요인으로 밝혀졌다.
[원문](https://arxiv.org/abs/2602.16763)

### Warp, 터미널 기반 코딩 에이전트 CLI 공개
Warp이 Ghostty, iTerm2, VS Code 등 임의의 터미널에서 동작하는 독립형 코딩 에이전트 'Warp Agent CLI'를 공개했다. 작업 복잡도에 따라 비용을 자동 최적화하는 멀티모델 라우팅과 디렉터리 이동 간 세션 유지, 에이전트 기반 대화형 앱(sqlite, vim, 디버거) 제어, 클라우드 에이전트 핸드오프 등 멀티플렉싱 아키텍처가 특징이다.
[원문](https://www.warp.dev/blog/introducing-the-warp-agent-cli-coding-agent)
