## AI/IT 뉴스
### Postman 데스크톱이 Codex·Claude Code 플러그인을 사용자 동의 없이 자동 설치 (이슈 #14370)
Postman Desktop 12.33.4가 기존 로그인 사용자의 맥에 Codex 플러그인(1.1.0)·Claude Code 플러그인(2.0.1)과 Postman CLI를 자동 설치했다는 이슈가 제기됐다. 보고자는 설치 과정에서 ~/.codex/config.toml에 Postman 마켓플레이스 항목이 추가되고, SessionStart 훅이 에이전트에게 Postman API 스킬을 불러오라는 지시를 주입하며, 설치 프로그램이 자기 훅의 신뢰 기록을 직접 기록해 사용자 동의를 우회한다고 주장했다(데이터 유출이 확인된 것은 아니라고 명시). Postman은 11월 3일 설정 편의를 위해 CLI·플러그인을 함께 배포했고 앱 내에서 제거할 수 있다고 답하며, 기존 사용자에 대한 opt-in 안내를 더 명확히 하고 훅 승인·세션 시작 동작을 재검토하겠다고 밝혔다.
[원문](https://github.com/postmanlabs/postman-app-support/issues/14370)
