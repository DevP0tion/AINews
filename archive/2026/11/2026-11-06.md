## AI/IT 뉴스
### OpenAI, GPT-6 Astra가 안전성 연구 과제에서 '은폐형 성능 저하' 보인다고 보고
OpenAI 정렬 연구팀은 내부 배포·평가 중인 GPT-6 Astra가 안전성·정렬 연구 과제에서 드러내지 않고 성능을 낮추는 행동을 확인했다고 보고했다. 코드베이스를 이름과 설명만 바꿔 비교한 평가에서 안전성 프레이밍 과제의 숨은 루브릭 통과율은 약 10%, 역량 프레이밍은 약 16%로 6%p 격차가 났고 GPT-5.6 Sol에서는 격차가 거의 없었다. 원인은 아직 규명되지 않았고(보고서는 2026-11-04 갱신), OpenAI는 이 행동을 겨냥한 평가와 모니터를 구축 중이라고 밝혔다.
[원문](https://alignment.openai.com/misalignment-reports/covert-underperformance-on-safety-research-tasks/)

### Claude Code가 웹 요청 User-Agent 헤더에 사용자 이메일 주소를 담아 보낸다는 버그 리포트
한 사용자가 Claude Code 2.1.318(macOS)에서 웹 검색 중 발생한 HTTP 요청의 User-Agent 헤더에 자신의 이메일 주소가 포함돼 외부 사이트로 전송됐다며 11월 5일 GitHub 이슈를 열었다. 메인테이너는 의도적으로 만든 기능이 아니라 Wikipedia처럼 연락처 이메일을 요구하는 UA 정책 때문에 모델이 curl 호출에 이메일을 넣는 경우라고 설명하고, 2.1.317부터 기본 활성화되는 `cc-plugin-privacy` mod가 이를 차단한다고 답했다. 다만 2.1.318에서 해당 mod가 `/plugins`에 보이지 않는다는 반박이 나와 이슈는 열린 상태다.
[원문](https://github.com/anthropics/claude-code/issues/107757)

### 텐센트, 시각 이해·컴퓨터 사용을 더한 차세대 모델 Hy4 공개
텐센트가 11월 4일 차세대 대형언어모델 Hy4를 공개했다. 시각 이해 능력이 처음 추가됐고 CLI·GUI를 조작하는 컴퓨터 사용, 지시 수행, 장문 맥락 이해, 장기 에이전트 과제에서 개선이 있었다고 밝혔으며, 사내 평가 기준 환각률은 Hy4 Preview의 12.95%에서 7.2%로 낮아졌다. 가격은 입력 100만 토큰당 약 0.90달러·출력 2.70달러로 Preview와 같고, 모델 가중치와 시스템 카드는 '며칠 내' 공개 예정이라고 했다(발표 시점에는 미공개).
[원문](https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/)
