### Disagreement among frontier LLMs on real-world fact-checks
실제 팩트체크 대상 1,000개에 GPT-5.4, Claude Opus 4.7, Gemini 3 Pro 등 최전선 LLM 5종의 판정을 비교한 결과, 전체 사례의 67%에서 모델 간 의견 불일치가 발생했습니다. 판정 차이가 2단계 이상인 실질적 불일치도 34%에 달했으며, 완전 합의는 True·False 극단에서만 나타났습니다. 팩트체크 등 정확성이 중요한 영역에서 단일 LLM에 의존하는 것의 위험성을 실증적으로 보여준 연구입니다.
[원문](https://lenz.io/research/llm-disagreement)

## Claude/Anthropic 업데이트
### 모델/API
- **Claude Opus 4.8 출시**
  Anthropic이 Claude Opus 4.8을 출시했습니다. 기존 4.7과 동일한 가격($5/$25 per million tokens)을 유지하면서 코딩·에이전틱·추론 벤치마크에서 성능이 향상되었고, API 식별자 `claude-opus-4-8`로 즉시 사용 가능하며 Fast mode는 표준 요금의 2배(2.5배 속도)로 제공됩니다.
  [출처](https://www.anthropic.com/news/claude-opus-4-8)

### 제품
- **Claude Code v2.1.154: Dynamic Workflows 정식 출시 및 Opus 4.8 기본 탑재** ⚠️
  Claude Code v2.1.154에서 수십~수백 개의 서브에이전트를 병렬 오케스트레이션하는 Dynamic Workflows가 정식 출시되었고(`/workflows`로 실행 현황 확인), Opus 4.8이 기본 모델로 설정되었으며 `/simplify` 명령이 cleanup-only 리뷰 방식으로 개선되었습니다.
  [출처](https://github.com/anthropics/claude-code/releases/tag/v2.1.154)
