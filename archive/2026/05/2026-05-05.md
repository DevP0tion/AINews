## AI/IT 뉴스
### DeepClaude – Claude Code agent loop with DeepSeek V4 Pro
DeepClaude는 Claude Code의 에이전트 루프를 그대로 유지하면서 API 호출을 로컬 프록시(localhost:3200)로 가로채 DeepSeek V4 Pro 등 저비용 백엔드로 전달하는 오픈소스 도구다. DeepSeek V4 Pro 기준 출력 토큰 비용이 $0.87/M으로 Anthropic 대비 약 17배 저렴하며, 세션 중 백엔드를 즉시 전환하는 기능도 지원한다. 파일 작업, bash 실행, git 연동, 서브에이전트 등 Claude Code의 전체 기능을 그대로 사용할 수 있다.
[원문](https://github.com/aattaran/deepclaude)

### The agent harness belongs outside the sandbox
AI 에이전트 하네스를 샌드박스 내부가 아닌 외부에 배치해야 한다는 아키텍처 제안이다. 하네스를 외부에 두면 LLM API 키·사용자 자격증명을 샌드박스에 노출하지 않고, 유휴 샌드박스를 약 25ms 만에 중지·재개하거나 장애 시 즉시 대체 인스턴스를 프로비저닝할 수 있다. 스킬·메모리 경로는 데이터베이스로 라우팅하고 워크스페이스 경로만 샌드박스로 전달해 다중 사용자 공유 상태도 처리한다.
[원문](https://www.mendral.com/blog/agent-harness-belongs-outside-sandbox)
