### Zyphra Hierarchical Attention: 트리 인덱서로 attention을 subquadratic으로
KV cache 위에 키 요약을 재귀적으로 압축한 트리를 만들고, 쿼리가 이 트리를 위에서 아래로 내려가며 희소한 키 부분집합만 가져오는 ZHA(Zyphra Hierarchical Attention) 기법이다. 트리 깊이가 시퀀스 길이에 따라 늘어나 라우팅과 최종 attention 비용이 sublinear하게 증가하며, 전체적으로 quadratic보다 낮은(superlinear) 복잡도를 달성한다. 기존 사전학습 모델에도 수십억 토큰 규모의 짧은 KL distillation만으로 적용 가능하고, long-context 검색·추론·수학·agentic 코딩 평가에서 성능을 유지했다고 보고한다. 저자들의 성능 모델에 따르면 100만 토큰 이상 컨텍스트에서 경쟁 기법을 앞선다.
[원문](https://arxiv.org/abs/2610.42112v1)

### Asynchronous Flow Map Language Models: 생성 순서를 1-step 병렬 생성에 내재화
autoregressive 모델은 토큰을 순차적으로, masked diffusion 모델은 여러 스텝에 걸쳐 채워 넣으며 생성 순서의 이점을 얻지만, 1-step 병렬 생성에서 순서를 활용하는 방법은 불분명했다. aFMLM은 토큰별 time schedule로 각 토큰의 denoising 진행도를 상대적으로 조절하는 asynchronous flow의 flow map을 학습해, 순서 정보를 hidden 연산 안에 넣은 상태로 모든 토큰을 단일 forward pass에서 생성한다. 고정된 schedule과 상태 적응형 학습 schedule을 모두 다루고 distillation 기법도 함께 제시하며, Sudoku 풀이와 GSM8K 코드 생성에서 one-step 기준 SOTA를 기록했다고 주장한다.
[원문](https://arxiv.org/abs/2610.42018v1)

### JavaScript 프레임워크 선택의 'AI 비용'을 12종 벤치마크로 측정
Nolan Lawson이 Claude Opus 5.5로 동일한 PokéAPI 앱을 12개 프레임워크·구성으로 각각 중간값 5회(Angular는 빌드 실패로 3회) 생성시켜, 에이전트 실행 비용·시간·토큰과 Lighthouse 지표를 함께 측정했다. 중간값 기준 비용은 Hono+htmx가 $2.67로 가장 낮고 Angular가 $4.97로 가장 높았으며, 토큰은 Nuxt 3.85M에서 Angular 9.76M까지 벌어졌고 전송 JavaScript는 Astro 약 0KiB·Next.js 142KiB였다. 저자는 승자를 선언하지 않고 LLM 무작위성과 Lighthouse의 MPA 선호 등 한계를 명시하면서, "프레임워크가 에이전트에 더 좋다"는 주장을 검증 없이 받아들이지 말고 재현 가능한 벤치마크를 공개하자고 제안한다.
[원문](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/)
